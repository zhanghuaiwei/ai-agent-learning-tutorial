# 规则、人工与 LLM 评测

> 预计 7 小时｜目标：组合可靠评测器，不迷信单一 LLM Judge。

## 1. 三类评测器

- 规则：Schema、引用 ID、Tool 名、预算、关键词禁令；便宜、稳定、优先使用。
- 人工：业务正确性、可操作性、风险；质量最高但慢，适合金标准与争议样本。
- LLM Judge：语义正确性、忠实度、完整性；可扩展但也有偏差、位置效应和版本漂移。

能用确定性规则判断的，不交给 Judge。Judge Prompt 写明确评分标准、给证据和参考答案，要求只返回结构化分数与简短理由；抽样与人工一致性校准。

## 2. 评分量表

例如正确性 0～3：0 完全错误/危险；1 有关键错误；2 基本正确但遗漏；3 与证据一致且完整。把抽象“好不好”拆成正确性、忠实度、可执行性、语气与安全。

Judge 不应看到不必要的候选名称，防止偏好；A/B 次序随机；定期用人工标注计算一致率。

## 3. 项目任务

实现 5 个规则评测器、2 个 LLM Judge 和 20 条人工金标。统计 Judge 与人工一致率，分析分歧并调整 Rubric。

## 4. 练习与答案

### 练习 1：Judge 和被测模型用同一模型有问题吗？

**答案：**可能共享偏差。至少用人工校准，关键场景可使用不同模型或多评测器，不把 Judge 当绝对真相。

### 练习 2：人工评分不一致怎么办？

**答案：**先完善定义与示例，对争议样本仲裁；一致性差说明量表模糊，不是简单平均就能解决。
