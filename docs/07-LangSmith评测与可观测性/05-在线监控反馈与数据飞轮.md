# 在线监控、反馈与数据飞轮

> 预计 6 小时｜产出：从线上信号安全地产生下一轮评测样本。

## 1. 在线指标

系统指标：请求量、成功/超时/429、P50/P95/P99、队列、依赖错误。Agent 指标：任务完成、平均步数、Tool 错误、循环、审批转化、拒答。成本指标：每任务 Token/费用、缓存命中、模型分布。安全指标：越权拦截、注入检测、敏感输出事件。

告警必须可行动。例如“5 分钟内提交 Tool 失败率 > 5% 且请求数 > 20”，而不是单次异常就叫醒人。设 SLO：核心只读任务可用性、P95、工单重复创建为 0。

## 2. 反馈闭环

点赞/点踩只是弱信号。收集失败原因、用户改写、人工修正和放弃步骤，经脱敏、权限审查、去重、标注后进入候选数据集；人工批准后加入回归集。线上数据不能直接自动训练或改变 Prompt。

监控模型/Prompt/数据版本分布，发布使用灰度或特性开关，异常可快速回滚。

## 3. 项目任务

设计一页 Dashboard 和三条告警；模拟检索退化、上游 429、重复工具趋势，写处置步骤。把 5 个失败 Trace 转为合格数据集样本。

## 4. 练习与答案

### 练习 1：点赞率下降能证明模型退化吗？

**答案：**不能单独证明，可能是用户分布、界面、延迟或样本偏差；结合任务、组件和版本指标分析。

### 练习 2：为何不自动把用户输入加入数据集？

**答案：**可能含隐私、错误标注、攻击文本与数据授权问题，必须治理后再使用。

## 5. 验收与资料

指标有负责人和处置动作，反馈进入数据集前有审核。参考 [Observability](https://docs.langchain.com/langsmith/observability)、[Online evaluations](https://docs.langchain.com/langsmith/online-evaluations)。
