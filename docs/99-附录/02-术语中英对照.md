# Agent 术语中英对照

| 英文 | 本教程中文 | 准确含义 |
|---|---|---|
| Agent | 智能体/Agent | 在边界内感知上下文、选择动作并迭代完成任务的系统 |
| Agent Loop | Agent 循环 | 模型—动作—观察—继续/停止的执行循环 |
| Tool Calling | 工具调用 | 模型提出结构化调用，应用校验并真正执行 |
| Structured Output | 结构化输出 | 按 Schema 生成并通过运行时验证的数据 |
| Prompt Engineering | 提示工程 | 设计指令、示例和输出约束 |
| Context Engineering | 上下文工程 | 动态选择、组织和治理整个模型上下文 |
| RAG | 检索增强生成 | 从外部知识检索证据后辅助生成 |
| Embedding | 嵌入向量 | 将文本映射到可计算相似度的向量表示 |
| Chunk | 文档片段 | 可独立检索且保留来源的知识单元 |
| Retriever | 检索器 | 根据查询返回候选文档的组件 |
| Reranker | 重排器 | 对候选做更精细相关性排序 |
| Recall@k | 前 k 召回率 | 正确证据是否进入前 k 候选的比例 |
| MRR | 平均倒数排名 | 第一个正确结果排名的倒数均值 |
| Groundedness | 依据性/忠实度 | 回答陈述是否受给定证据支持 |
| Hallucination | 幻觉 | 无充分依据却生成事实、引用或动作 |
| State | 状态 | Graph 节点之间传递的可持久化数据 |
| Reducer | 状态归并器 | 决定多个 State 更新如何合并 |
| Checkpoint | 检查点 | 某执行步后的持久化 State 快照 |
| Thread | 运行线程/会话线 | 关联跨多次调用的持久化执行上下文 |
| Interrupt | 中断 | 保存状态并等待外部输入后恢复 |
| Human-in-the-loop | 人在回路 | 人工查看、批准、编辑或拒绝关键动作 |
| Idempotency | 幂等性 | 重复请求产生与一次相同的业务效果 |
| Side Effect | 副作用 | 对外部世界产生的写入、通知或状态变化 |
| Trace | 追踪 | 一次端到端执行及其子步骤树 |
| Run/Span | 运行片段 | Trace 内单个模型、工具或节点操作 |
| Dataset | 评测数据集 | 带输入、参考、标签和规则的样本集合 |
| Experiment | 实验 | 在固定数据集上运行某系统版本并比较 |
| LLM Judge | 模型评审器 | 用模型按 Rubric 评估另一输出的方法 |
| MCP | 模型上下文协议 | Host/Client/Server 连接上下文与工具的协议 |
| Guardrail | 护栏 | 输入、动作、输出或策略层的约束与检测 |
| Prompt Injection | 提示注入 | 恶意内容试图改变模型指令或诱导动作 |
| Least Privilege | 最小权限 | 只授予完成当前任务必需的能力 |
| Circuit Breaker | 熔断器 | 依赖持续失败时快速拒绝并探测恢复 |
| Backoff/Jitter | 退避/抖动 | 重试等待逐步增长并加入随机扰动 |
| SLO | 服务目标 | 对可用性、延迟或质量的目标承诺 |
| P95 | 95 分位 | 95% 样本不超过该值，反映尾部表现 |
| ADR | 架构决策记录 | 保存背景、候选、决定、后果和证据 |
| Runbook | 运行手册 | 告警发生时可执行的诊断与恢复步骤 |

## 练习与答案

### 练习 1：Tool Calling 是否等于 Tool Execution？

**答案：**不等。前者是模型建议，后者是应用完成校验、授权后执行。

### 练习 2：Checkpoint 是否等于业务数据库备份？

**答案：**不等。Checkpoint 保存执行状态，业务数据库保存权威业务事实。
