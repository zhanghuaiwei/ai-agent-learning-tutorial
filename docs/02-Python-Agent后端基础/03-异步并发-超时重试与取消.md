# 异步并发、超时、重试与取消

> 预计 7 小时｜产出：并发调用模型与工具的可靠执行器。

## 1. 心智模型

Agent 服务大部分时间在等待模型、数据库和 HTTP，属于 I/O 密集型。`async` 让线程在等待时处理别的任务，不会自动让 CPU 计算变快。同步 SDK 或大文件解析会阻塞事件循环，应换异步客户端或用线程池隔离。

```python
import asyncio

async def collect_context(equipment_id: str):
    async with asyncio.timeout(3):
        async with asyncio.TaskGroup() as tg:
            alarm = tg.create_task(get_alarm(equipment_id))
            manual = tg.create_task(search_manual(equipment_id))
        return alarm.result(), manual.result()
```

`TaskGroup` 中一个任务异常时会取消同组任务。捕获 `CancelledError` 做清理后通常继续抛出，不能吞掉取消。

## 2. 超时与重试

连接、读取、整次操作分别设置超时。只重试瞬时且可安全重放的失败，如 429、部分 5xx、连接中断；参数错误、鉴权失败、安全拒绝不重试。用指数退避加随机抖动；写操作必须带幂等键。

## 3. 项目任务

实现 `ReliableInvoker`：总超时、最多两次重试、指数退避、并发信号量、取消传播、耗时指标。Fake Provider 模拟 429、超时、永久 400 和取消。

## 4. 练习与答案

### 练习 1：为什么所有异常都重试更不稳定？

**答案：**永久错误不会恢复，还会放大流量、延迟、费用；非幂等写操作可能重复执行。

### 练习 2：客户端断开后模型调用是否继续？

**答案：**普通问答通常取消；进入业务事务的操作按业务语义完成或补偿，不能只看连接状态。

## 5. 验收与资料

并发数不越界；超时按预算返回；取消无遗留任务；重试原因可观测。参考 [asyncio](https://docs.python.org/3/library/asyncio.html)、[TaskGroup](https://docs.python.org/3/library/asyncio-task.html)、[HTTPX 超时](https://www.python-httpx.org/advanced/timeouts/)。
