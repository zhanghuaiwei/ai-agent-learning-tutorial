# 设备工具助手 M2 验收

> 第 10 周里程碑｜目标：完成可演示、可测试、可控的 LangChain 单 Agent。

## 1. 必交能力

- LangChain 1.x `create_agent`，没有复制过时 API。
- 设备、告警、手册、工单草稿工具；按角色动态暴露。
- Runtime Context 身份来自服务端。
- 自有 SSE 事件适配；步骤/Token/Deadline 执行边界、循环检测和安全错误。
- Fake 与真实模型共用同一 Agent 接口。

## 2. 定量门槛

在不少于 40 条数据集上：工具选择准确率 ≥ 90%；参数结构有效率 100%；越权拦截率 100%；任务终止率 100%；P95 和单任务成本均有报告。阈值未达标要写失败分类，不得只挑成功截图。

## 3. 练习与答案

### 练习 1：工具选择错误率高，第一步换大模型吗？

**答案：**先按错误分类检查工具重叠、描述、参数、上下文和数据集；只有确认模型能力是瓶颈，再以质量/成本评测决定升级。

### 练习 2：如何证明已有工程经验对项目有增益？

**答案：**展示稳定 SSE 契约、取消与断线体验、审批交互、防重复提交和可调试运行详情；但面试重点仍放在后端 Agent 可靠性。

## 4. 演示与复盘

演示正常多工具任务、越权拦截、流式进度、循环终止、费用报告。提交 M1 与 M2 对照：框架减少了什么代码，又带来哪些版本与抽象成本。

通过后进入 RAG；如果检索知识仍靠把手册整段塞进 Prompt，则 M2 不算完成。
