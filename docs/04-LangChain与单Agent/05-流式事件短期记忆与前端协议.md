# 流式事件、短期记忆与前端协议

> 预计 7 小时｜产出：将 LangChain 内部流安全转换为自有 SSE 协议。

## 1. 流式的三类信息

- 模型文本增量：用于打字效果。
- Agent 状态更新：步骤完成、工具开始/结束。
- 自定义进度：检索、审批等待、评测等业务事件。

对外建立 Allowlist 映射，未识别内部事件不发送。工具参数可能含敏感信息，默认只发工具显示名、阶段和安全摘要。

## 2. 短期记忆

短期记忆服务于一个 Thread 内的连续交互。记忆不是把全部历史无限追加：要按 Token 预算保留近期消息、关键事实和状态；摘要也是模型生成数据，重要业务事实应从数据库重新读取。

区分：

- `conversation_id`：产品会话标识。
- `thread_id`：Graph 持久化运行上下文。
- `run_id`：一次执行。
- `request_id`：一次 HTTP 请求。

## 3. 断线与背压

客户端消费慢时要限制缓冲；断线触发取消或后台继续策略。SSE 每条事件带 `seq/run_id/timestamp`，最终事件只出现一次；Tool 重试不应让 UI 误显示重复副作用。

## 4. 当前 Streaming Mode 与适配

LangChain 当前常用三种 Stream Mode：

| Mode | 含义 | 对外建议 |
| --- | --- | --- |
| `updates` | 每个 Agent Step 的 State Update | 映射为安全的阶段进度 |
| `messages` | 模型 Token/内容块及元数据 | 只发送允许展示的文本块 |
| `custom` | 业务代码主动发送的进度 | 映射为检索、审批等业务事件 |

当锁定的 LangGraph 版本支持 v2 Streaming 时，显式使用 `version="v2"`，统一读取 `type/ns/data`：

```python
async for part in agent.astream(
    {"messages": [{"role": "user", "content": command.message}]},
    context=command.context,
    stream_mode=["updates", "messages", "custom"],
    version="v2",
):
    safe_event = stream_adapter.to_public_event(part)
    if safe_event is not None:
        yield safe_event
```

`stream_adapter` 使用 Allowlist，不把未知事件直接透传。尤其不要把模型推理内容、Tool 原始参数、Checkpoint State 和内部节点名作为稳定前端协议。

课程对外 SSE 协议从第 2 阶段第 4 章的四个核心事件出发，本章随 Agent 能力扩展为完整集合（与[企业级项目蓝图](../01-总览与使用方式/03-企业级项目蓝图.md)的事件契约一致）：

```text
run.started        # 核心事件（第 2 阶段第 4 章已落地）
message.delta       # 文本增量（命名与第 2 阶段一致）
run.progress        # 稳定业务阶段（如"检索中"），不是节点名
tool.started        # 第 2 阶段预留的工具事件命名
tool.completed
tool.failed
input.required      # 需要用户补充信息
approval.required   # Human-in-the-loop 审批等待
run.completed
run.failed
run.cancelled
run.execution_limit_reached
```

所有终态互斥且只发送一次。`run.completed` 到达后不能再出现 Delta；客户端按 `run_id + seq` 去重。

## 6. 练习与答案

### 练习 1：为什么前端不应解析 LangGraph 节点名？

**答案：**节点属于内部实现，重构会破坏客户端；前端只依赖稳定业务事件。

### 练习 2：对话摘要能当业务事实源吗？

**答案：**不能。摘要可能遗漏或改写；告警状态、审批结果应从权威系统读取。

### 练习 3：客户端断开是否一定要取消 Agent？

**答案：**不一定。交互式问答可取消以释放资源；进入审批或需要可靠后台交付的任务可能继续。必须按 Use Case 明确策略，并让客户端能通过 Run API 查询最终状态。

## 7. 验收与资料

流事件无敏感字段、顺序可测、断线行为明确。参考 [LangChain Streaming](https://docs.langchain.com/oss/python/langchain/streaming)、[Short-term memory](https://docs.langchain.com/oss/python/langchain/short-term-memory)。
