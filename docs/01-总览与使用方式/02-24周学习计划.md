# 24 周压缩排期参考

> 本文件只用于在 2027 年投递窗口前安排优先级，不再限制教程内容，也不能用周数代替能力验收。默认路线请先阅读[无固定周期的能力门槛学习路线](09-无固定周期的能力门槛学习路线.md)。若门槛未通过，应回退补缺；新增岗位专题按真实 JD 继续学习，不因第 24 周结束而删除。

## 1. 时间边界

- 核心学习：2026-08-31 至 2027-02-14，共 24 周；
- 总投入：约 360 小时；
- 投递准备：2027-02-15 至 2027-02-28；
- 目标面试：2027 年 3 月初。

每周默认 15 小时：教程与官方资料 3 小时、编码 7 小时、测试/练习 2 小时、计算机基础 2 小时、复盘/面试 1 小时。

如果某周只能投入不足 10 小时，优先保留编码、测试和复盘，阅读可顺延；不得通过跳过验收直接追赶日期。

## 3. 每周详细计划

## 第 1 周：基线测评与最小模型调用

**日期：2026-08-31 ～ 2026-09-06**

学习内容：

- 确认 Python、Git、HTTP、SQL 和命令行基线；
- 使用 `uv` 创建项目和虚拟环境；
- 配置千问与 DeepSeek API Key，不在代码中硬编码；
- 使用统一 OpenAI-compatible SDK 完成同步和流式调用；
- 记录模型、Token、耗时和错误。
- 建立岗位证据矩阵，对应用开发、Agent 平台、算法和推理 Infra 岗分类。

项目增量：建立 `model-gateway` 最小项目，完成 `/health` 和 `/chat`。

横向基础：HTTP 请求/响应、JSON、状态码、环境变量和 Secret。

验收：

- API Key 不进入 Git；
- 千问调用成功，DeepSeek 至少完成连通性验证；
- 能解释一次模型调用从前端到供应商 API 的完整链路；
- 生成第一份学习基线报告。

## 第 2 周：Python 类型、数据模型与错误

**日期：2026-09-07 ～ 2026-09-13**

学习内容：

- 类型标注、`dataclass`、Protocol、泛型的必要部分；
- Pydantic Schema、校验器与配置；
- 异常分类：用户错误、供应商错误、超时、限流和内部错误；
- 分层错误码和结构化日志。

项目增量：建立内部 `ModelGateway` 接口与 Qwen/DeepSeek Adapter。

横向基础：栈、堆、引用、可变对象、异常栈。

验收：供应商可通过配置切换；错误不会以原始异常直接暴露给调用者；核心 Schema 有单元测试。

## 第 3 周：异步、并发、超时与重试

**日期：2026-09-14 ～ 2026-09-20**

学习内容：

- `async/await`、并发限制、取消与资源清理；
- 超时、指数退避、抖动、可重试与不可重试错误；
- 为什么重试可能造成重复副作用。

项目增量：模型调用增加超时、有限重试、并发信号量和请求 ID。

横向基础：进程/线程/协程、并发与并行、I/O 密集型任务。

验收：通过 Fake Provider 模拟超时、限流、成功重试和最终失败，不消耗真实 API。

## 第 4 周：FastAPI、SSE 与测试闭环

**日期：2026-09-21 ～ 2026-09-27**

学习内容：

- SSE 流式事件设计；
- pytest、Fixture、Mock、集成测试；
- 日志脱敏和 Usage Record。
- SQLAlchemy 2 最小 Repository 与第一条 Alembic Migration。
- 设计 `JobQueue` Protocol、202 Job API 和可查询状态，不在本机安装 Redis。

项目增量：完成模型网关 M0，提供非流式/流式接口、健康检查、费用记录、可迁移数据表和测试。

横向基础：HTTP 长连接、SSE 与 WebSocket 的区别。

阶段验收：从空环境按 README 启动；在线 Smoke Test 成功；离线测试覆盖主要错误路径。

## 第 5 周：LLM 必需原理与 Prompt

**日期：2026-09-28 ～ 2026-10-04**

- Prompt 版本、变量、证据和输出约束。

项目增量：设备维护问答 Prompt v1，建立 10 条 Golden Cases。

横向基础：Unicode、编码、序列化和 Token 与字符的区别。

验收：对同一批 10 条 Prompt Case 比较千问/DeepSeek，完成模型边界与微调决策 ADR 初稿；Tool/RAG 部分在第 10/14 周补齐，不以单个示例下结论。

## 第 9 周：Agent 中间件、记忆概念与流式事件

**日期：2026-10-26 ～ 2026-11-01**

验收：UI 不展示私密推理文本；事件顺序可测试；失败事件能被前端正确处理；Prompt 伪造身份不能改变 Tool 权限。
