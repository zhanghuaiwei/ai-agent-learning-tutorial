# Agent 系统设计题

> 目标：在 35～45 分钟内完成需求澄清、架构、数据、安全、可靠性和取舍。

## 1. 通用框架

1. 澄清用户、任务、风险、规模、延迟、数据与成功指标。
2. 确定性流程、RAG、单 Agent、Graph 的选择。
3. 画 API、模型网关、编排、Tool、数据源、存储和观测。
4. 深挖一个关键链路与状态机。
5. 权限、注入、隐私、审批、幂等。
6. 超时、重试、限流、降级、恢复、容量。
7. 测试、评测、上线灰度、反馈闭环。
8. 成本与演进。

## 2. 题一：企业知识与工单 Agent

重点：文档 ACL、版本、混合检索、引用/拒答；Tool 最小权限；Graph Interrupt；幂等提交；RAG/轨迹分层评测。

## 3. 题二：客服 Agent

重点：身份验证、订单/退款高风险动作、知识时效、转人工、会话状态、峰值限流、敏感数据脱敏。退款不应由文本“确认”触发。

## 4. 题三：研发助手/MCP

重点：仓库权限、代码/Issue 注入、Shell 与网络沙箱、MCP Server 信任、Secrets、变更 Diff、审批、审计与供应链。

## 5. 练习与答案

### 练习 1：系统设计一开始就选 LangGraph 合适吗？

**答案：**先澄清流程是否跨请求、有审批和恢复；从需求推出组件，而非先报技术栈。

### 练习 2：面试官问规模但没给数字怎么办？

**答案：**提出合理假设并标注，例如日 10 万请求、峰值 100 RPS，再说明规模变化会如何影响队列、缓存和存储。

## 6. 验收

每周画两题，限定 40 分钟；复盘遗漏项，保留架构版本变化。
