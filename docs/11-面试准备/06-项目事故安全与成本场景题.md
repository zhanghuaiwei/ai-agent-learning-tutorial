# 项目事故、安全与成本场景题

> 使用 STAR+R：Situation、Task、Action、Result、Reflection；结果必须来自真实练习。

## 1. 模型费用突然增长 5 倍

**答题骨架：**先用 Feature Flag 限制非核心任务；按版本、租户、模型、重试和步骤分解；检查循环、Prompt 变长、缓存失效、流量异常；修复并回归质量；增加预算硬门禁和异常告警。

## 2. RAG 返回其他租户文档

**答题骨架：**按最高等级数据事件隔离相关检索；保全证据、确认影响；修复服务端 ACL 过滤与索引命名空间；清缓存；通知流程按规定执行；加入跨租户硬门禁和持续审计。不要只加 Prompt。

## 3. 工单重复创建

**答题骨架：**停止自动提交；按幂等键查影响并补偿；根因通常是成功响应丢失 + 无唯一约束/多层重试；修复业务幂等记录、状态 UNKNOWN 和调和器。

## 4. Prompt Injection 触发危险 Tool

**答题骨架：**禁用 Tool/连接，审计动作；权限最小化、文档不可信标记、参数验证、可信审批、输出限制；将载荷加入红队集。承认注入无法只靠识别文本彻底消除。

## 5. LLM Judge 指标很好但人工不满意

**答题骨架：**抽样校准 Judge、检查 Rubric 与数据分布；引入人工金标和规则评测；按分组定位偏差，不直接用更多 Judge 掩盖问题。

## 6. 练习与答案

### 练习：每个场景录制两分钟回答，必须包含哪四类证据？

**答案：**用户/业务影响、技术 Trace/指标、数据一致性或安全检查、修复后的自动回归与监控。没有真实生产经历时明确说是故障注入演练。
